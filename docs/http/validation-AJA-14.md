## TDD e validações

A implementação usa o JSON Server sob `/api/v1`; o export estático segue fazendo autenticação e comandos no browser. As referências e bytes dos anexos são consultados com escopo do servidor.

The runner log labels the staff POST 403 as the expected controlled negative request; navigation cancellations and the offline vote request are not treated as successful HTTP calls.
